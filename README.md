Yuwen Unit 4 — a review gate-runner

这是一个第四单元语文复习闯关门游戏（gate-runner），改编自开源项目 [royashbrook/shootit](https://github.com/royashbrook/shootit)（MIT）。原作者 Roy Ashbrook。本仓库是面向个人与家庭使用的教育改编版。

This is a Unit 4 语文 (Chinese language arts) review gate-runner, adapted from [royashbrook/shootit](https://github.com/royashbrook/shootit) (MIT). Original author: Roy Ashbrook. Educational adaptation for personal and family use.

## 怎么玩 / How to play

用手机浏览器打开下面的 GitHub Pages 地址即可开始，无需安装：

Open this URL on a phone. No install:

https://charsiu888.github.io/yuwen-unit4/

左右滑动，冲过左右两扇答案门。选对，伙伴翻倍；选错，伙伴减少。躲开史莱姆，打败魔王。页面加载后可离线游玩。

Slide left or right to run through an answer gate. A correct answer grows your crowd; a wrong one shrinks it. Dodge the slimes and beat the boss. After the page loads, it plays offline.
